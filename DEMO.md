# FutureLab: 90-second demo

**One idea to land:** the AI explains, the code calculates, and nothing is presented as a prediction.

## Before you present (2 minutes)

1. Open your live site about **2 minutes early** and run a preset, to wake the free server.
2. Keep one tab open on the Lab page. Zoom the browser to about 110%.
3. Close other tabs and silence notifications.
4. Have your **share link** and the **phone view** ready as backups.

## The script

| Time | Do | Say |
|---|---|---|
| 0:00 | Landing page, then click **Start Exploring** | "FutureLab turns a what-if question into a simulation you can actually explore, and it never pretends to predict the future." |
| 0:08 | Click the **Savings** chip. Point at the variable tags and the Assumptions panel | "Savings of 2,000 a month for a year. Look: what I stated is tagged User input, and what the app assumed is tagged Assumption, with every assumption listed." |
| 0:20 | Click **Run Simulation**. Hover the chart. Point at **Calculated** and the limitations | "24,000 rupees. These numbers come from plain code, not the AI, and it tells you what the model leaves out." |
| 0:32 | **Pin as Scenario A**. Change 2,000 to 3,000, **Run**, **Pin as Scenario B** | "Now what if I save 3,000 instead? Both scenarios sit on one chart, and the table shows B is 12,000, or 50%, higher." |
| 0:50 | In **Ask FutureLab**, click **Which variable matters most?** | "The engine nudges each input and measures the effect, then the AI explains it in plain language." |
| 1:05 | Type **What changes if I save 4000?** and click **Ask**. Point at the card | "The AI proposes the change, but the engine calculates the result, so the numbers are never made up." |
| 1:17 | Click **Copy share link** | "And anyone can open this exact scenario from a link." |
| 1:23 | Stop talking, smile | "The AI explains, the code calculates, and every result says 'under these assumptions'. That's FutureLab." |

## If something goes wrong

| Problem | What to do |
|---|---|
| Site is slow to load | It was asleep. Wait up to a minute, and next time wake it earlier |
| "AI service is overloaded" | Presets and simulations don't need the AI. Say so, and use **Explain** or **Which variable matters most?**, which still answer (tagged *Generated without AI*) |
| The what-if question fails | Skip it and use **Copy share link** instead. It needs no AI |
| Wi-Fi fails | Run `npm run dev:all` locally, or show a screen recording you made earlier |
| You lose your place | Open the share link and start again from the results |

## Rehearse it

Run the script three times with a timer. Record a backup screen recording of one clean run.
